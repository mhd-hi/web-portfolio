# My Gatsby portfolio

## Edit The Site

All portfolio text and links live in [`src/config.js`](src/config.js). Edit the arrays to add or remove jobs, projects, technologies, navigation links, or social links. Add a photo by setting `about.imageSrc`.

## Development

```sh
yarn install
yarn develop
```

## GitHub Pages

Push to `main` and the included GitHub Actions workflow builds and deploys the site to GitHub Pages. In the repository settings, open **Pages** and set the source to **GitHub Actions**.
